# TOMAGOCHIK

## [⬇ Скачать для Mac](https://github.com/teuton05-ops/TOMAGOCHIK/releases/latest/download/Tamagochi.dmg)

**Mac с чипом Apple M · macOS 13+ · установка без Терминала**

Откройте скачанный DMG, перетащите **Tamagochi.app** на **Applications («Программы»)**
и запустите приложение из «Программ». Питомец появится на рабочем столе, а лапка —
в строке меню; отдельного окна и значка в Dock нет.

При блокировке первого запуска откройте **Системные настройки → Конфиденциальность
и безопасность → Всё равно открыть** и подтвердите запуск. Приложение пока не
заверено Apple. [Инструкция Apple](https://support.apple.com/ru-ru/102445).

[Все версии и описание обновлений](https://github.com/teuton05-ops/TOMAGOCHIK/releases).

Для обновления закройте питомца через меню лапки и замените приложение в «Программах»
новой версией из DMG. Настройки сохраняются.

**TOMAGOCHIK («Тамагочи»)** — приложение для macOS, которое поселяет на рабочем
столе маленького пиксельного питомца: рыжего котика, собаку или обоих сразу.
Питомцы гуляют по экрану, отдыхают, играют в мячик и реагируют на события на Mac.
Они живут поверх рабочего стола, а управление доступно через иконку лапки в строке меню.

Кроме анимаций, у питомца есть полезные функции:

- **Напоминания.** Двойной клик по питомцу открывает форму: укажите текст и время.
- **Файлы «в зубах».** Перетащите файл на питомца, чтобы он подержал его, а затем
  заберите перетаскиванием обратно в Finder или другое приложение.
- **Инструменты для файлов.** Через меню можно конвертировать поддерживаемые
  форматы, извлекать текст из изображений и PDF, сжимать файлы для отправки
  и удалять фон у изображений. Удаление фона требует macOS 14 или новее.
- **Реакции на окружение.** Питомцы реагируют на музыку, снимки экрана,
  пробуждение Mac и погоду.
- **Настройка внешнего вида.** Можно выбрать котика, собаку или двух питомцев
  и один из трёх размеров в отдельном окне настроек. Там же включаются болтовня,
  танцы под музыку, позирование для скриншотов и прогулки по элементам окон.
  В разделе «Внешний вид» доступны четыре окраса отдельно для котика и собаки,
  плавная регулировка размера от 50% до 200% и непрозрачность от 35% до 100%.
  В поведении можно настроить скорость, сон без активности, погоню за курсором,
  частоту болтовни и звук напоминаний. Сброс настроек сохраняет напоминания и файлы.

Приложение написано на Swift и AppKit.

## Сборка из исходников

Для обычной установки используйте готовый DMG по ссылке выше. Если хотите собрать
приложение самостоятельно, следуйте инструкции ниже. Знание Swift не требуется.

### 1. Проверьте совместимость

- Нужен **MacBook с чипом Apple Silicon** (серия M) и **macOS 13 или новее**.
- Узнать чип и версию системы можно в меню ** → Об этом Mac**.
- Текущий скрипт сборки рассчитан на **arm64**. Для MacBook с Intel готовая
  инструкция сборки в этом проекте пока не предусмотрена.
- Для сборки нужны актуальные **Xcode Command Line Tools** со Swift и SDK macOS 14
  или новее. Полный Xcode не обязателен.

### 2. Установите инструменты сборки

Откройте **Терминал** через Spotlight (`⌘ + пробел`, затем «Терминал») и выполните:

```sh
xcode-select --install
```

Подтвердите установку в появившемся окне и дождитесь завершения.
Если инструменты уже установлены, система сообщит об этом — переходите дальше.
Подробнее: [инструкция Apple](https://developer.apple.com/documentation/xcode/installing-the-command-line-tools/).

### 3. Скачайте и соберите приложение

Выполните команды по очереди в Терминале:

```sh
mkdir -p ~/Projects
cd ~/Projects
git clone https://github.com/teuton05-ops/TOMAGOCHIK.git
cd TOMAGOCHIK
./build.sh
```

После успешной сборки появится сообщение `Готово: build/Tamagochi.app`.
Спрайты уже входят в проект; устанавливать Python или Pillow для запуска не нужно.

### 4. Перенесите приложение в «Программы»

Откройте папку со сборкой:

```sh
open build
```

В Finder перетащите **Tamagochi.app** в папку **«Программы»**.
Затем запустите его из этой папки двойным кликом. На рабочем столе появится питомец,
а в строке меню — лапка. Отдельного главного окна и значка в Dock у приложения нет.

Если macOS заблокирует запуск из-за неизвестного разработчика, после попытки
открытия перейдите в **Системные настройки → Конфиденциальность и безопасность**
и нажмите **«Всё равно открыть»** для этого приложения.
Подробнее: [открытие приложений на Mac — справка Apple](https://support.apple.com/ru-ru/102445).

### 5. Разрешите нужные функции

- **Универсальный доступ:** откройте **Системные настройки → Конфиденциальность
  и безопасность → Универсальный доступ**, добавьте установленный `Tamagochi.app`
  кнопкой `+`, если его нет в списке, и включите переключатель. Это позволяет
  питомцу использовать элементы окон как площадки для передвижения.
- **Геолокация:** разрешите доступ при запросе, если хотите реакции на местную погоду.
- **Доступ к файлам:** разрешайте доступ к папкам при запросе, когда передаёте
  питомцу файлы из «Документов», «Загрузок» или с рабочего стола.

После выдачи разрешений при необходимости закройте приложение через меню лапки
и откройте его снова из «Программ».

## Управление

- Меню открывается по нажатию на лапку в строке меню или правому клику на питомце.
- Пункт **«Настройки…»** открывает большое отдельное окно. Когда приложение активно,
  его также можно открыть сочетанием **⌘,**. Изменения применяются и сохраняются сразу.
- В меню можно выбрать питомца, размер, мячик и работу с файлами.
- **«Сидеть в уголке»** в меню лапки или настройках поведения закрепляет питомцев
  в нижнем углу экрана. В настройках можно выбрать левый или правый угол.
  Чтобы вернуть прогулки, выключите этот режим.
- Для снимка можно заранее выбрать **«Позировать для снимка (30 секунд)»** в меню
  лапки или **«Позировать сейчас»** в настройках поведения. При открытом инструменте
  macOS «Снимок экрана» автоматическая поза длится 5 секунд с начала съёмки,
  даже если выбор области продолжается дольше.
  Для мгновенного снимка всего экрана надёжнее включить позу заранее.
- Двойной клик по питомцу открывает новое напоминание.
- Чтобы завершить работу, нажмите на лапку и выберите **«Выход»**.

## Как обновить сборку из исходников

Закройте приложение через меню лапки. В Терминале выполните:

```sh
cd ~/Projects/TOMAGOCHIK
git pull --ff-only
./build.sh
open build
```

Замените прежний `Tamagochi.app` в «Программах» новой сборкой и запустите его.
Скрипт использует сертификат `Tamagochi Dev`, если он есть в связке ключей,
иначе — временную подпись. При временной подписи после пересборки может
понадобиться заново добавить приложение в «Универсальный доступ».

## Файлы проекта

- `app/` — исходники приложения.
- `art/` — Python-скрипты генерации пиксельной графики; требуется Pillow.
- `sprites/` — готовые спрайты для приложения.
- `preview/` — изображения и анимации для просмотра.
- `build.sh` — сборка приложения в `build/Tamagochi.app`.

Спрайты питомцев рисуются в разрешении **128×128 на кадр**, с прозрачным фоном.
Размер питомца на экране задаётся отдельно в меню. Чтобы перерисовать все 32
спрайт-листа и обновить анимационные превью, установите Pillow и выполните:

```sh
python3 art/cat.py
python3 art/dog.py
```

Сгенерированные сборки в `build/` исключены из Git.

## Подготовка установщика

На Mac с инструментами сборки выполните:

```sh
./release.sh
```

Скрипт заново собирает приложение, проверяет подпись и создаёт
`build/Tamagochi.dmg` с ярлыком «Программы» и инструкцией установки.
Рядом сохраняется контрольная сумма `build/Tamagochi.dmg.sha256`.
При публикации в GitHub Releases прикрепляйте оба файла, сохраняя имя
`Tamagochi.dmg`: на него ведёт кнопка скачивания.
